Archive File Check

Check that archive files are present in the media folder, and optionally that their CRC32 still matches, to find missing or corrupted files. Checks run in the background workers.

What to check
Archives in the chosen folders and their subfolders, inside the media folder {{ media_root }}.
Selected archives are always checked, even if binned or marked as deleted. With a filter, the filter is applied again when the check starts.
Options
Without CRC32, a check opens each zip's file list and compares the size of its images (uncompressed) with the stored one, which is fast. With CRC32, the whole file is read and compared instead. Archives marked as deleted are skipped, except when chosen by id.
